# Student Task & Progress Manager

## Project Overview
The Student Task & Progress Manager is a responsive web application designed to help students organize academic tasks, set priorities, manage due dates, and track their progress.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## Features
- Add, edit, and delete tasks
- Set task priorities
- Assign due dates
- Mark tasks as completed or pending
- Search and filter tasks
- View total, pending, and completed task counts
- Track overall completion progress
- Save tasks in browser Local Storage
- Responsive design for desktop and mobile

## How to Run
1. Download or clone this project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using a web browser or Live Server.
4. Add tasks and manage your progress.

## Data Storage
Tasks are stored in the browser's Local Storage. Data is specific to the browser and website origin being used.
